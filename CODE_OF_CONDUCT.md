# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The summary below is for convenience; the linked text is the full standard.

## Expected behaviour

- Be respectful and considerate in issues, pull requests, and reviews.
- Criticise code and ideas, not people.
- Accept that others have different experience levels and viewpoints.
- Take responsibility for mistakes and correct them.

## Unacceptable behaviour

- Harassment, insults, or personal attacks of any kind.
- Sexualised language or imagery, and unwelcome attention.
- Publishing someone's private information without their permission.
- Using this project's spaces to share or request help with attacking systems
  you are not authorised to test.

## Scope

This applies in the repository's issues, pull requests, and discussions, and
anywhere someone is representing the project.

## Reporting

Report a problem privately to the maintainer,
[@stackadnan](https://github.com/stackadnan), using the contact details on
that GitHub profile. Do not open a public issue for a conduct report. Reports
are kept confidential.

## Enforcement

The maintainer may edit or remove comments, commits, and issues that break
these rules, and may warn, temporarily block, or permanently block the person
responsible, depending on severity and repetition.
